# Experiment 1: Binomial Probability Distribution

## Objective
To study the Binomial Probability Distribution using Wolfram Demonstrations.

## Experiments
1. Number of trials n = 10, probability p = 0.25.
2. Number of trials n = 10, probability p approximately 0.5.
3. Number of trials n = 20, probability p approximately 0.5.

## Learning Outcome
Understood how the number of trials and probability of success affect the binomial distribution.
